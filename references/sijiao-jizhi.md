# AI 私教机制（诊断·双循环·SM2复习·学习者画像）

本文件是本 Skill 的「私教引擎」，把 Skill 从静态资料库升级为**会诊断、会出题、会复习的私教**。核心闭环：

```
诊断 → 教学 → 练习 → 复盘 → 调度 → 再诊断
```

机制来源（均已验证）：DeepTutor 双循环方法论（HKUDS/DeepTutor 理念，ndpvt-web/deeptutor-claude-skill 落地）、EduClaw SM2 算法与学习者画像（amit15110003/EduClaw 源码级参数）、FSRS 记忆模型（open-spaced-repetition/fsrs-cli）。

---

## 一、诊断系统（10 题定位瓶颈）

### 1.1 触发

用户说「先诊断我」「开始」「我第一次来」→ 出诊断题。

### 1.2 诊断题组成

资料分析 4 题（覆盖基期/增长率/比重/盐水类，对应基础/进阶/综合三层）+ 数量 2 题 + 判断 2 题 + 言语 2 题。

### 1.3 三级判定

| 诊断结果 | 模式 | 策略 |
|---------|------|------|
| 0–3 题对 | 零基础唤醒模式 | 从速算和 ABRX 起步，每日量减半，先求会再求快 |
| 4–6 题对 | 专题突破模式 | 按知识图谱逐级通关，薄弱专题优先 |
| 7–10 题对 | 提速冲刺模式 | 限时训练 + 综合分析题策略 + 考场模拟 |

诊断结果写入学习者画像（见第五节）。

## 二、知识图谱（考点依赖与通关规则）

### 2.1 分层结构

- **基础层**：ABRX + 截位直除 + 415 份数法 + 特殊分数转化
- **进阶层**：假设分配 + 基期现期增长量增长率 + 比重平均数倍数 + 分数比较法
- **综合层**：盐水类★ + 比较类★ + 隔级比重★ + 拉动增长/贡献率★ + 乘积增长率 + 平均数增长率 + 比重变化 + 年均增长率 + 间隔增长率（详见 `ziliao-jinjie.md`）
- **实战层**：综合分析题（`ziliao-zonghe.md`）+ 套题节奏 + 时间管理

### 2.2 通关规则（硬性）

**基础层有错题 → 禁止进入进阶层；进阶层有错题 → 禁止进入综合层。逐级通关。**

### 2.3 前置依赖标注（prerequisite）

每个考点标注前置，教学前先验证前置已全部「掌握」：

| 考点 | 前置依赖 |
|------|---------|
| 比重变化 | 增长率 + 比重 |
| 盐水类 | 增长率 + 方程 |
| 隔级比重 | 比重 |
| 拉动增长/贡献率 | 增长量 |
| 乘积增长率 | 增长率 |
| 平均数增长率 | 平均数 + 增长率 |

## 三、双循环解题法 v2（DeepTutor 版）

### 3.1 循环 A — 分析（Investigate）

先不计算，只答四问：1. 关键词 2. 题型 3. 找什么数据 4. 用什么公式。全对才进循环 B。

**分析循环五原则：**

1. **推演优先于查找**：能从已知公式推出来的，不回去翻材料
2. **精准定位**：回材料只找特定的数（「2023 年出口额」），不整段重读
3. **去重**：已找到的数据不重复找
4. **及时止损**：某条线索找不到，立刻换角度，不死磕
5. **信息充分即停**：够列式了就动手算，不过度分析

### 3.2 循环 B — 计算（Solve）

按「分步链」执行：列式 → 速算 → 对答案。复杂题拆步骤，每步标明角色：

| 步骤角色 | 干什么 | 公考对应 |
|---------|--------|---------|
| 计算 | 数值运算 | 截位 / 415 / 假设分配 |
| 推导 | 公式变形 | ABRX 互推、十字交叉 |
| 分析 | 题型拆解、定性判断 | 趋势法、双线法 |
| 整合 | 多步结果合成结论 | 综合分析题四说法 |

### 3.3 归因

循环 A 错 → 回知识点重讲（识别/公式问题）；循环 B 错 → 归因训练（计算/条件问题）。把「想」和「算」分开，断档一目了然。

## 四、出题规则 v2

1. **三档难度标定**：基础（换数字）/ 综合（换场景）/ 陷阱（换问法考易错点），对应变式 A/B/C 级
2. **选择题**：唯一正确答案 + 三个「有迷惑性的」干扰项——干扰项必须来自真实错误路径（截位错/公式混/时间陷阱），不许凑数
3. **一次只呈现一道题**（除非用户要批量），答完立即反馈：判定 → 解析 → 标注考点出处
4. 所有题必须基于方法库真实考点出，不编造不存在的题型
5. 解析必须带「识别标志」，让用户下次自己能认出同类题

### 4.1 错题归因模板

| 错因类型 | 判定标志 | 针对性训练 |
|---------|---------|-----------|
| 公式记错 | 思路对列式错 | 抄正确公式 10 遍 + 同类题 5 道 |
| 识别错误 | 题型判断错 | 专项识别训练：只看题干说公式名 |
| 计算错误 | 列式对结果错 | 速算册 1 页 + 截位判定专项 |
| 条件遗漏 | 掉入时间/单位/范围陷阱 | 强制「三秒扫陷阱」训练 |

### 4.2 变式题生成（每道错题 A/B/C 三级）

- A 级（基础）：换数字同公式
- B 级（综合）：换场景同公式
- C 级（陷阱）：换问法考易错点——**C 级最重要，专门攻击思维盲区**

## 五、间隔重复调度（SM2 算法版）

> 弃用固定 1/3/7/15 天，改为 SM2 动态调度：间隔由答题质量实时算出。

### 5.1 四档评分（对答案后自评）

| 评分 | 含义 | 口诀 |
|------|------|------|
| 0 | 完全不会（重来） | 进度清零，明天重做 |
| 3 | 勉强对（困难） | 间隔缓慢增长 |
| 4 | 正常对（良好） | 标准增长 |
| 5 | 秒对（简单） | 间隔快速拉长 |

### 5.2 SM2 算法规则（EduClaw 源码实测参数）

```
评分 < 3        → 进度清零，间隔 = 1 天
第 1 次做对     → 1 天后复习
第 2 次做对     → 6 天后复习
之后            → 间隔 = 上次间隔 × EF
EF 初始 2.5，每次更新：EF′ = EF + (0.1 − (5−q) × (0.08 + (5−q) × 0.02))，EF 下限 1.3
```

### 5.3 速查示例

| 表现 | 间隔序列 |
|------|---------|
| q=5 连对 | 1 天 → 6 天 → 15 天 → 38 天 → 95 天 |
| q=3 勉强对 | 1 天 → 6 天 → 13 天 → 27 天 |
| q<3 | 回 1 天重计 |

**效果**：秒对的题间隔越拉越长，总错的题天天见——时间自动花在薄弱点上。

### 5.4 记忆三状态模型（FSRS 概念版）

每道错题在脑中有三个状态，复习安排据此判断：

| 状态 | 含义 | 私教判断动作 |
|------|------|-------------|
| 稳定性 S | 记住能管多久 | S 小 → 近期必复习；S 大 → 可拉长间隔 |
| 难度 D | 这题对用户多难 | D 高 → 拆成更小步骤重教，而非单纯重练 |
| 可提取性 R | 此刻还能想起多少 | R 掉到 90% 以下 → 立即安排复习 |

【目标保留率 90%】复习最佳时机是「快忘但没忘」（R≈90%）。SM2 是简化实现；用户若用 Anki，建议直接开 FSRS 调度，本 Skill 按 SM2 规则推送即可。

【口诀】秒对间隔翻倍走，勉强维持系数走，错了清零重新走。

## 六、学习者画像与游戏化

### 6.1 画像六维

模块掌握度 / 题型薄弱点 / 错误类型分布 / 速度瓶颈 / 连续正确率 Streak / XP 等级。

### 6.2 游戏化规则

| 项目 | 规则 |
|------|------|
| XP 经验值 | 做对 +10 | 变式 C 级做对 +20 | 完成当日复习队列 +15 |
| 等级 | 每 100XP 升 1 级：Lv1–3 基础筑基 / Lv4–6 专题突破 / Lv7+ 冲刺上岸 |
| Streak | 每日至少完成 1 次复习即续，断更清零——断 Streak 比错题更该提醒 |
| 掌握标记 | 同题型连续对 5 题 → 标记「掌握」，退出日常队列进月度池 |

### 6.3 调整规则

- 模块 < 50% → 降级基础
- 计算错误率 > 30% → 强制速算
- Streak 断 → 首日双倍复习量

### 6.4 档案持久化

每次对话结束更新画像：`{各模块掌握度, SM2复习队列(含下次日期), XP/等级, Streak, 下阶段计划}`。
用户说「记一下进度」写档，说「继续上次」读档。**每次对话开始先读档再教学。**

### 7.1 错题本模板

```
【错题编号】模块-序号 | 【日期】 | 【来源】套题第X题
【题目】（抄录或拍照）
【我的答案】X | 【正确答案】X
【错因归类】公式/识别/计算/条件遗漏（四选一）
【正确思路】一句话：识别标志 → 公式 → 速算路径
【同类拓展】A/B/C 级变式各 1 道
【SM2 队列】下次复习日期：X 月 X 日
```

### 7.2 套题复盘四步

1. 各模块正确率表（目标：常识 50% / 资料 90% / 判断 80% / 言语 75% / 数量 40%）
2. 时间分配对比目标
3. 错因计数（知识盲区/技巧不熟/粗心/时间不够）
4. 改进措施 + 下套目标（总分 + 重点模块）

## 八、引导式教学流程（用户说「教我 XX 考点」时）

三阶段，禁止一次性灌完：

1. **定位**：查知识图谱，列出该考点全部前置依赖 → 先确认前置已掌握，缺哪个补哪个
2. **交互讲解**：每讲一个概念 → 出一道快问验证 → 卡住就换更简单例子重讲 → 答对才推进下一个
3. **收尾**：串讲全部概念的依赖关系（谁是谁的前置）→ 建议下一个考点

---

## 九、输出质量闸门

输出前自检三条红线：

1. **计算过程可追溯**（每步能复算）
2. **归因不笼统**（禁止只写「粗心」）
3. **画像已更新**（错题/XP/SM2 队列写入学习者档案）
