## 一、盐水类（混合增长率）★

### 1.1 适用场景

已知两部分增长率求整体，或已知整体和一部分求另一部分。

### 1.2 核心结论

- 整体增长率**介于两部分之间**，偏向**基数大**的一方
- 【定性口诀】**整体在中间，偏向量大边**

### 1.3 十字交叉法

```
(R − R1) : (R2 − R) = B : A   （增速差之比 = 量的反比）
```

### 1.4 示例

出口增长 10%（量 1000），进口增长 20%（量 2000），进出口总额增速？

→ 整体在 10%–20% 之间，偏向 20%
→ (R−10):(20−R) = 2000:1000 = 2:1
→ 3R = 50 → **R ≈ 16.7%**

### 1.5 易错点

- 「偏向」只用于定性排除选项，精算必须十字交叉
- 量用**基期量**更严谨，但选项差距大时用现期量可接受
- 平均数混合（如人均收入）同样适用十字交叉

## 二、隔级比重 ★

### 2.1 适用场景

已知 A 占 B、B 占 C，求 A 占 C。

### 2.2 公式

```
A/C = (A/B) × (B/C)
```

【口诀】**连环比重，直接相乘**

### 2.3 示例

某省 GDP 占全国 10%，该省第三产业占该省 50%，第三产业占全国？
→ 10% × 50% = **5%**

### 2.4 易错点

- 连乘链不能断（必须是同一主体嵌套：省→省三产→全国）
- 反求时用除法：已知 A/C 和 A/B，求 B/C = (A/C)÷(A/B)

## 三、比较类（双线法/趋势法/增量大小比较）★

### 3.1 双线法

画两条线比较分子分母变化幅度：
- 分子涨得快 → 分数变大
- 分母涨得快 → 分数变小

### 3.2 趋势法

| 条件 | 结论 |
|------|------|
| a > b | 比重/平均数上升 |
| a < b | 比重/平均数下降 |
| a = b | 不变 |

（a=部分增速，b=整体增速）

### 3.3 增量大小比较

**大大则大，一大一小看倍数。**
- B 大 R 大 → X 一定大
- B 大 R 小 / B 小 R 大 → 比较 B 的倍数与 R 的倍数，倍数差大者胜

### 3.4 易错点

- 趋势法只能判断**方向**（升/降），算**幅度**必须套公式
- 「一大一小看倍数」是比 B 与 (1+R) 的综合，不是只比 R

## 四、拉动增长与贡献率 ★

### 4.1 公式

| 概念 | 公式 | 含义 |
|------|------|------|
| 拉动增长 | 部分增长量 / 整体基期量 × 100% | 拉动整体增长几个**百分点** |
| 贡献率 | 部分增长量 / 整体增长量 × 100% | 对整体增长的贡献占比 |

### 4.2 区别

**拉动增长看整体基期，贡献率看整体增量。**

### 4.3 示例

GDP 增长 1000 亿，消费增长 600 亿，GDP 基期 10000 亿：
- 消费拉动增长 = 600/10000 = **6 个百分点**
- 消费贡献率 = 600/1000 = **60%**

### 4.4 易错点

- 两者分母不同，题目问「拉动……个百分点」用基期，问「贡献率」用增量
- 各部分贡献率之和 = 100%，各部分拉动百分点之和 = 整体增速

## 五、乘积增长率

### 5.1 适用场景

总量 = A × B（如总额=量×价），求总量增速。

### 5.2 公式

```
R = R1 + R2 + R1×R2
```

### 5.3 简化规则

双双 < 10% 乘积项可忽略；有一个过 10%，乘积要估一估。

### 5.4 示例

销量增 15%，单价增 8% → 15% + 8% + 1.2% = **24.2%**

## 六、平均数增长率 vs 比重变化（终极辨析）

| 问法 | 公式 | 分母记忆 |
|------|------|---------|
| 「平均……增长百分之几」→ 平均数增长率 | r = (a−b)/(1+b) | 分母跟着**个数**走 (1+b) |
| 「比重变化几个点」→ 比重变化 | Δ ≈ 现期比重 × (a−b)/(1+a) | 分母跟着**部分**走 (1+a) |

【记忆】平均数 → (1+b)；比重 → (1+a)

### 易错点

- 平均数增长率结果带 **%**，比重变化结果是**个百分点**
- 判断上升/下降用趋势法（第三节），算数值才用本节公式

## 七、年均增长率 / 间隔增长率

### 7.1 年均增长率

【口诀】算倍数，找锚点，分几格，定位数，反推率。
- 末期/基期 = (1+r)^n，先算总倍数，再按 n 年开方估算
- 估算：r ≈ (总增速)/n 再略向下修正（复利效应）

### 7.2 间隔增长率

隔一年（如 2024 对 2022）：R = r1 + r2 + r1×r2（同乘积增长率公式）

- 【盐水类】整体在中间，偏向量大边。十字交叉法，增速差反比

- 【比重变化公式】比重跟着部分走，分母是 (1+a)
